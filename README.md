# Relat-rio-de-dados
repositório (limite de ~350 caracteres).  Dataset abrangente com indicadores globais de adoção, investimento e impacto da Inteligência Artificial (2017–2025). Dados consolidados de fontes institucionais (McKinsey, Stanford HAI, World Bank, IBM) em arquivos .csv e .xlsx para pesquisas, análise de dados e políticas públicas. Licença CC BY 4.0.
